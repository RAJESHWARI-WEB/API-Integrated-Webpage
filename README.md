*DESCRIPTION*: 

This project is a simple yet efficient Weather Forecast Web Application that utilizes API integration to fetch and display real-time weather data and a 5-day forecast for any city entered by the user. The application is built using HTML, CSS, and JavaScript, and it leverages the OpenWeatherMap API for obtaining weather information.

The core idea of the project is to demonstrate how external APIs can be integrated into a web application to enrich user experience and deliver dynamic content. The interface is user-friendly, allowing users to simply enter a city name and view both the current weather and a detailed 5-day forecast instantly.

Functionality Overview:

The project consists of three main files: index.html, style.css, and app.js.

HTML (index.html): The structure of the web app is defined in this file. It includes an input box for entering the city name, a button to trigger the API request, and two tables to display current weather and forecast data. Headings and semantic elements ensure accessibility and clarity.

CSS (style.css): Styling is handled in this file to enhance the visual appeal and readability. A clean and modern layout is created with proper spacing, colors, and font styles. Tables are styled using a responsive and minimal design, with hover effects and vibrant headings to distinguish data clearly.

JavaScript (app.js): The core logic and API integration reside here. When a user enters a city and clicks the "Get Weather" button, JavaScript fetches data from the OpenWeatherMap API. It first retrieves the current weather conditions such as temperature and description, and then fetches the 5-day forecast. The forecast is filtered to display data at 12:00 PM each day for consistency. The results are dynamically inserted into the HTML tables using DOM manipulation.

Key Features:

It emphasizes both functional and visual aspects, making it a great learning experience for beginners and intermediate developers interested in building interactive, API-powered applications.
